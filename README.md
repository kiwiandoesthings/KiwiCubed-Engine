# KiwiCubed Engine

Much of this is hashed over already on the wiki link at the bottom, but I'll explain it here quickly.

KiwiCubed is an engine that comes with a default content pack. This is the most factual way to describe this project. The default content pack means it can be played as a standalone game. However, it is possible to remove that default mod, and instead just use the engine as a framework to make an entirely new game. However, even so, the default mod (VanillaCubed) homes many essential or basic features and pieces of content (like the main menu). I'll refer to KiwiCubed interchangeably as an engine and game for this reason.
This game is basically designed around being moddable though, so much of the development time simply comes from making every feature receptive to mods.

If you want more info, please look [here](https://wiki.kiwiandoesthings.place/wiki/Main_Page).
